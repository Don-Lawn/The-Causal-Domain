Each layer introduces a new symmetry, a new behaviour, and a new type of boundary that can restrict that behaviour.

## **5. Symmetry Locks: How Boundaries Shape Behaviour**

Every symmetry introduces a freedom. Every boundary restricts that freedom.

A **Q‑lock** is the mechanism by which a boundary, horizon, or internal constraint limits the expression of a symmetry without destroying it.

Q‑locks unify phenomena that appear unrelated:

- gravitational time‑lock
- EM exclusion in conductors
- color confinement
- SUSY breaking

They are the universal mechanism by which the universe shapes the freedoms introduced by symmetry.

## **6. Composition vs Layering**

A crucial distinction in the framework is between:

- **Layering** — adding a new dimension (Pᵢ)
- **Composition** — assembling structures within a layer

Layering changes the rules. Composition changes the arrangements.

This distinction clarifies why:

- quarks and protons are in the same layer
- electrons and atoms are in the same layer
- stars and black holes are in the same layer

Layer transitions are rare and fundamental; composition is ubiquitous and structural.
