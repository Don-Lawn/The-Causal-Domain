# **Duality Cluster (Overview)**

The Duality Cluster gathers together the core concepts that express how RR handles oppositions, complements, and mirrored structures. These entries form a relational constellation: each one is a different mode of the same underlying symmetry. This page is the hub for navigating that constellation.

## **Cluster Map**

At the centre is **Duality**, the generative symmetry. Radiating from it are four immediate expressions:

- **Domain Pair** — duality applied to what exists
- **Dual Frame** — duality applied to how it is seen
- **Dual Projection** — duality applied to how it is mapped
- **Fourfold Tension** — duality applied to how it stabilises

Each entry links back here, and links to the others where conceptually relevant.

## **Entries in This Cluster**

### **Duality →**

Defines the core symmetry that underlies all other entries in the cluster. Click here when you want the central principle from which the rest radiate.

### **Domain Pair →**

### **Dual Frame →**

Describes how perspective determines which side of a duality becomes foreground. Helpful when exploring why the same pair can appear inverted.

### **Dual Projection →**

Explains how dual structures appear when mapped into lower‑dimensional or constrained views. Go here when you want to see how duality behaves under representation.

### **Fourfold Tension →**

Shows how duality stabilises into a four‑way structure of constraints and balances. Useful when examining how dual systems maintain coherence.

## **How to Use This Cluster**

Start with **Duality** if you want the generative idea. Jump to any spoke if you’re exploring a specific mode. Return here whenever you want the bigger picture or to switch conceptual neighbourhoods.
